# VALORANT Protocol Agent Registry

A clean, aesthetic web dossier for 15 VALORANT Protocol operatives. Built for people who care more about agent lore than actually checking their corners in-game.


## What is this?

Look, we all know you're hardstuck Gold 2 blaming your team's instalock Reyna. So instead of deranking again on Ascent, take a breather and browse classified protocol files in a soft blush pink UI that looks 10x cleaner than your crosshair placement.

No bloat, no 800mb node_modules folder, just pure front-end goodness that runs faster than a Neon sprinting down B Long on Fracture.

---


## Quick Start (Eco Round Friendly)

1. Clone or download this repo.
2. Double-click `index.html`.
3. That's literally it. No npm install, no 10-minute build pipeline, no technical timeouts.

## Project Files

- `index.html` — The main protocol terminal, hero layout, and dossier grid.
- `styles.css` — The pink aesthetic, 3D math transforms, and responsive rules.
- `script.js` — The agent database, orbital scroll engine, and role filter logic.
