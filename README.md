# VALORANT Protocol — Agent Registry

A minimal, responsive web showcase and lore dossier for 15 VALORANT Protocol operatives. Built with pure HTML, CSS, and JavaScript with zero external frameworks or dependencies.

## Features

- **Circular Scroll Showcase**: Desktop scroll-driven 3D split roll with orbiting operative titles and portraits.
- **Agent Dossiers**: Detailed lore profiles, real names, origins, combat abilities, and specialties for 15 operatives.
- **Role Filtering**: Live filter tabs for Controllers, Duelists, Initiators, and Sentinels.
- **Micro-Interactions**: Subtle 3D card tilt on mouse move, soft rose hover elevations, and portrait shine sweeps.
- **Theme**: Minimalist soft pink and cream palette with high-contrast typography.
- **Accessibility**: Semantic HTML, skip link, ARIA tabs, and reduced-motion support.

## Getting Started

No build process or installation is required.

1. Clone or download this repository.
2. Open `index.html` in your web browser.


## Project Structure

- `index.html` — Page markup, navigation, showcase container, and footer.
- `styles.css` — Design system variables, layout, and animations.
- `script.js` — Agent dataset, orbital scroll calculations, and filtering logic.
